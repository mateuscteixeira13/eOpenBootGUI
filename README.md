# eOpenBootGUI
eOpenBootGUI is a UEFI module that functions as the firmware configuration menu without modifying the firmware itself.

## WARNING!
This code is not complete, is in a alpha version. Check Changelogs to see the new features.

### Other warning
Mouse only works in real hardware, not in QEMU. Why? Well, basically, QEMU is not a full hardware with limitations, this is why mouse don't works in QEMU.
